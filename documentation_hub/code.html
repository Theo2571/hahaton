01. Installation

To begin, install the Aiva Core library using your preferred package manager. We recommend using pnpm for faster module resolution.

Terminal content_copy 
pnpm install @aiva/nebula-core

02. Initializing the Agent

The nebula client requires an API Key which can be generated from your workspace settings. Ensure you never expose this key in client-side code.

index.ts content_copy 
import { NebulaClient } from '@aiva/nebula-core';

// Initialize with high-precision neural parameters
const client = new NebulaClient({
  apiKey: process.env.AIVA_KEY,
  personality: 'luminous-editorial',
  temperature: 0.7
});

await client.connect();
console.log('Intelligence link established.');
